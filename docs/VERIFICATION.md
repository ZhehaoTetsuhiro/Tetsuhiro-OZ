# Tetsuhiro-OZ 验证记录（精确性证据）

本文件记录各模块的**独立验证证据**：解析公式对拍、第三方实现交叉验证、
守恒律检查与测试数字。所有数字来自本机 2026-10-15 的实际运行（可复跑）。
每个数字都对应测试中的断言（`go test ./...`）。

## 镀膜设计（coating）

- **交叉验证（与独立实现）**：把 OZ 的 TMM 结果与 Python `tmm` 包
  （Steve Byrnes，独立编写、被广泛使用的薄膜光学实现）逐点对比，
  同一套 n,k 数据、同一批膜系：
  - 单层 MgF2 100nm / BK7，0/30/45/60° 入射；
  - 12 层四分之一波堆 TiO2/SiO2 @550nm / BK7；
  - 任意 5 层堆 / 熔石英，0/30/60° 入射。
  - 共 **546 个工作点**（含 s/p 偏振）：**|ΔR|max = 1.0e-14，|ΔT|max = 1.1e-14**
    ——机器精度级一致。
  - 复跑方式：`go run ./tools/crosscheck > oz_tmm.json &&
    python3 tools/crosscheck/crosscheck.py oz_tmm.json`
- 物理层自测（coating 包测试套件）：单层 Airy 公式随机参数对拍 1e-12 级、
  四分之一波堆峰值反射率解析式、R+T+A=1、Brewster 角检查、相位/半波层语义、
  优化器端到端指标（宽带 AR / 高反堆 / V-coat 等，见 `go test ./coating/ -v`）。
- 模板端到端指标（1 nm 网格实测，均已冻结为测试阈值）：单层 AR 空气/BK7
  R=**1.2594%**（=解析最优，逐位相等）；V-coat 设计波长
  R=**9.1e-5 / 2.5e-5 / 2.0e-4**（420/550/680 nm）；宽带 AR 420–680
  平均 R=**0.697%**；1064 nm 14 对高反 **0.9997527**（=解析峰）；
  边沿滤光片阻带/通带按文档承诺全部达标；50/50 分光 |R−0.5|=**0.0072**；
  GrowLayers 2→4 层、merit 提升 2.1×。

## 镜头设计（lens）

- **处方 → 近轴**：双凸 BK7（R=±100mm, d=6mm）EFL 与厚透镜闭式解
  `1/f = (n−1)(1/R1 − 1/R2 + (n−1)d/(n·R1·R2))` 一致（判据 < 0.05mm，实测一致到 1e-9 级）。
- **消色差双胶合自主设计**（f=100mm，N-BK7/F2，f/5，f/4 口径 20mm；
  薄透镜解 → 厚透镜牛顿消色差 → DLS 抛光）：
  - EFL 偏差 **2.5µm**；F–C 焦点差 **11µm**（普通单透镜同口径约 1.5mm，改善 100×+）；
  - 点列图：轴上 RMS **4.1µm**（GEO 5.2µm）、0.5° 离轴 RMS **7.4µm**。
- **Monte-Carlo 公差分析**（±0.05mm 半径与厚度、±0.0005 玻璃熔炼 Δn）：
  2000 次运行良率 **63.6%**，失败全部归因焦距误差
  （均值 85µm，与灵敏度 δf/f ≈ δR/R 一致）；确定性可复现（同种子逐位一致）。
- 测试含 `-race` 全绿；优化器与公差引擎均确定性（固定种子、固定 tie-break）。

## 几何光学（geo）

- 基础层（追迹/近轴）：斯涅尔定律数值验证、平行平板位移、球面近轴焦点收敛性
  （孔径减半误差二次降）、抛物面镜严格聚焦 vs 球面球差、H-L 不变量守恒、
  时间反演系统等——随 `go test ./geo/ -v` 运行。
- 采样/分析/像差层（2026-10-15 交付，测试全绿 + `-race` 干净）关键实测：
  - 抛物面镜 OPD RMS = **6.6e-15 mm**（机器精度）；椭球共轭下 S1..S5 全为 0；
  - 对称系统 1:1 时 S2=S5 机器零；薄透镜置于光阑时 S5=0、实光线畸变 4e-16；
  - Petzval 曲率：薄透镜 = −n·f、球面镜 = −2c/n（精确）；
  - 点列图离焦半径 = r_p·Δz/L 解析一致；完美像点 RMS ≈ 1e-12；
  - 波前系数 vs 实光线 OPD 拟合：W040=−S1/8（比值 1.0003）、W131=−S2/2
    （0.997–0.999）、W222（±0.3%）、W220（±5%）；畸变 δh′ 与真实主光线 ≤2%；
  - 消色差双胶合（自主设计输出）F−C 焦距差 < 1e-6（相对）。
- **坐标断点 / 偏心倾斜（G1，2026-10-15 合并）**：约定为「先偏心 (dx,dy)，后绕
  x/y/z 倾斜，可选返回轴」，`geo/coordbreak.go` + `geo/pose.go`；
  - 倾斜平面镜的反射方向偏转 = 2θ（≤ 1e-12 rad）；偏心平板像移与解析式一致
    （≤ 1e-9 mm）；坐标断点与其逆组合为恒等（≤ 1e-12 mm）；
  - 无偏心无倾斜时既有数值**逐位不变**（回归测试锁定）；一阶引擎对含位姿系统
    显式报错（`TestPosedSystemRejectsFirstOrderEngines`）。
- **非球面（G2，2026-10-15 合并）**：`PolyAsphere`（任意正整数幂，含奇次）与
  `QAsphere`（Forbes Qcon/Qbfs，来源：Forbes Opt. Express 18(13) 13851 (2010)、
  18(19) 19700 (2010)；与 prysm 独立实现对拍）；
  - 解析斜率 vs 中心差分最大误差 **2.5e-10**（判据 1e-7）；求交 Newton 残差
    **≤ 8e-15 mm**（判据 1e-12）；仅偶次项与 `EvenAsphere` 逐点一致
    （矢高 0，斜率 5.6e-17）；QAsphere 零系数 = Conic（精确 0）；
  - 近轴 EFL 对 a₂ 的解析导数与有限差分一致 1.8e-11（判据 1e-6）；
    JSON 往返逐位一致。
- **偏振追迹（G5，2026-10-15 合并）**：`TracePolarized` 包装既有 `System.Trace`，
  每面重算 s/p 基底（3D 场），`CoatedAmplitudes` 支持镀膜 TMM；
  - 法向入射 Fresnel 系数 ~1e-16（判据 1e-12）；Brewster r_p=0（判据 1e-12）；
  - 能量守恒 16489 例实测 8.9e-16；斜入射平行平板闭式与独立 3D 求解一致 1.1e-15；
  - 与 `optics.StokesAt` 逐字段一致（5009 个 Jones 矢量，1.0e-14）。
- **几何 MTF / 场曲（G11，2026-10-15 合并）**：`geo/gmtf_mtf.go`、`geo/gmtf_field.go`；
  - 均匀圆盘光束 MTF vs 2·J1(x)/x：满量程最大误差 5.7e-4、M≥0.1 处 1.0e-4（判据 1%）；
  - 薄透镜场曲：Petzval 与解析式 6.7e-8；子午/弧矢面预测 2.4e-8；

  - 轴对称自由曲面与径向代理一致（矢高/追迹逐位相同）；
