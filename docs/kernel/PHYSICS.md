# 物理模型与数值方法（docs/PHYSICS.md）

本文定义 Tetsuhiro WOS 内核的全部物理约定、传播算法与精度边界。所有量均为 SI 单位。

## 1. 符号约定

- 时间因子 **exp(−iωt)**，单色场 E(x,y,z) = A(x,y,z)·e^{iφ(x,y,z)}；沿 +z 传播的平面波为 e^{+ikz}。
- 波数 k = 2π/λ；**强度 I = |Ex|² + |Ey|²**（W/m²，由光源功率归一化确定绝对标度）。
- 薄透镜相位 t = **exp(−ik r²/(2f))**：f>0 会聚、f<0 发散（与该时间约定自洽，已验证聚焦在 +f）。
- 相位板/光栅等一律以复透过率 t(x,y) 相乘（Ex、Ey 同乘），琼斯元件以 2×2 矩阵作用于 [Ex, Ey]ᵀ。

## 2. 离散网格与 FFT

- 网格 N×N（N 为偶数，2–262144），像素 dx = W/N。
- 空间坐标 **x(i) = (i − N/2)·dx**，i=0…N−1（x∈[−W/2, +W/2)，+W/2 点依 FFT 周期性省略）。
- 频率坐标 **f(i) = i/(N·dx)**（i≤N/2）、(i−N)/(N·dx)（i>N/2），Nyquist 频率 f_nyq = 1/(2dx)。
- 2-D FFT 为自行实现的 radix-2 Cooley-Tukey（行/列并行，复数 128 位精度）；非 2 的幂尺寸回退到 Bluestein（chirp-z）算法，归一化满足 F⁻¹F = 1，Parseval 守恒（测试覆盖）。

**采样要求**：任一平面上的相位梯度必须小于 π/像素，否则混叠（例如大倾角平面波、短焦距透镜边缘）。内核在 Fresnel 算法越界时自动告警（见 §4）。

## 3. 自由空间传播：角谱法（ASM，默认）

角谱法对标量亥姆霍兹方程在均匀介质中是**精确解**（无傍轴近似）：

    U(x,y,z) = F⁻¹{ F{U(x,y,0)} · H(fx,fy,z) }
    H = exp[ i k z sqrt(1 − (λfx)² − (λfy)²) ]       当 (λf)² ≤ 1（传播波）
    H = exp[ −k z sqrt((λf)² − 1) ]                  当 (λf)² > 1（衰逝波，物理衰减）

- **衰逝波**默认按指数衰减（物理正确）；可用全局参数 evanescent:"zero" 直接置零，或用 evanescent_limit（衰逝截断阈值，nepers）对深衰逝分量做带限式截断以避免下溢/上溢。
- 离散 ASM 的两类误差来源：
  1. **循环卷积环绕混叠**（wrap-around）：光束倾斜或发散时超出 N×N 窗口，包绕到对侧。用 **`asm_pad`（零填充角谱法）** 消除——把场嵌入 2N×2N 网格（同 dx）做线性卷积，传播后裁剪回 N×N 中央窗。
  2. **频谱贴边混叠**：倾斜光束频谱集中在带边，相位变化剧烈导致采样混叠。用 **`asm_shift`（离轴频移角谱法）** 消除——先搬移谱质心（载频），用平移后的传递函数 H(f+fc) 传播，再搬回载频。
  3. **走离超窗（几何不可表示）**：H 按 df = 1/(N·dx) 采样，频率 f 处的相位步进为 2πλz·f·df，超过 π 即混叠——实空间里就是光走出窗口后被循环卷积绕回。判据为 `|z|·λ·f_sig ≤ 窗口宽度 N·dx`（f_sig 为 90% 频谱功率半径，在**进入该步之前**的场上测量）；超过时告警 **asm_alias_wrap**。严格采样极限是半个窗口，但实测误差在超过半个窗口后仍很小（内置模板在 1.05–1.25× 半窗下仍与解析图样吻合），故只在“光整体走离超过一整个窗口”这一无歧义情形告警。**远场几何在固定网格上就是这样失效的**：光栅级次落在 z·λ/Λ（Λ=20 µm、z=1 m 时为 31.6 mm），远超 8 mm 窗口 → 图样被绕回成无结构拍频（曾静默发生）。
- **奈奎斯特带限**（bandlimit: {fraction:0.9, sigma:0.05}）与孔径元件 edge_sigma（0 = 理想硬边）抑制硬边全带宽频谱的混叠，是数值正则化，均可关闭。bandlimit 由模拟器在每个平面后施加**一次**（propagate 元件不再重复滤波）。
- **折返传播**：反射镜之后的 propagate 距离仍为沿光束方向的路程，相位按 +ik·s 继续累加（见 §6）。内核 API 也支持负 z（逆传播算子，用于反演类应用），此时衰逝波默认置零（不稳定放大），可设 backward_regularize:true + tikhonov_alpha 改用 Tikhonov 阻尼逆 A/(1+(αA)²) 改善反演；模拟器光路语义不使用负 z。

### 3.1 高精度变体

| 方法 | 原理 | 适用 | 代价 |
|---|---|---|---|
| asm | 精确角谱法（默认） | 常规光束 | 1× |
| asm_pad | 2N×2N 零填充线性卷积，消除窗口环绕 | 光束倾斜/发散、长距离、超出窗口 | 内存/耗时约 4× |

## 4. 菲涅耳与夫琅禾费近似

### 4.1 Fresnel 传递函数（fresnel_tf）

    H(fx,fy) = e^{ikz} · e^{−iπλz(fx²+fy²)}

**有效条件**（采样判据，违反时告警 fresnel_tf_alias）：|z| ≤ N·dx²/λ。

### 4.2 Fresnel 冲激响应（fresnel_ir）

    U2 = e^{ikz}/(iλz) · dx² · F⁻¹{ F{U1} · F{h} }，h = e^{iπr²/(λz)}（回绕布局：索引 0 ↔ 零偏移）

即黎曼和意义下的卷积（dx² 为面积元）。实现先置于 2N×2N 零填充网格再做 FFT 圆卷积后裁剪——**填充是正确性要求**：N 网格上核在 |偏移|=N/2 处回绕使啁啾相位缠绕方向翻转，窗口边缘的输出像素会出现假驻相点相干伪影；填充后所有有效采样对不回绕，圆卷积严格等于线性卷积（内存/耗时约 4×，同 asm_pad）。输出网格与输入相同。**有效条件**：|z| ≥ N·dx²/λ（违反时告警 fresnel_ir_alias）。与 fresnel_tf 互补。注意夫琅禾费公式中的输出二次相位因子 e^{iπr²/(λz)} 在此处**不**出现——卷积核已携带该相位。

### 4.3 夫琅禾费远场（fraunhofer）

    U_out(x) = e^{ikz}/(iλz) · e^{ikr²/(2z)} · dx² · F{U_in}，x = λz·f

**输出像素尺寸变为 dx' = λ|z|/(N·dx)**（网格物理宽度 = λ|z|/dx）。实现中把 FFT 输出按 N/2 平移，保持与输入相同的“中心在网格中央”布局。**布局要点**：中心化输入布局 x(i) = (i−N/2)·dx 下，原始 DFT 与采样连续傅里叶变换相差棋盘因子 e^{iπ(p+q)}——仅做 fftshift 会让输出复场带 (−1)^{i+j} 的奈奎斯特棋盘相位（强度不可见、相位与后续相干使用错误），实现中在平移前补偿该因子（复场级回归测试 `TestFraunhoferComplexFieldExact` 锁定）。**有效条件**：菲涅耳数 F = D²/(λ|z|) << 1（D 为**输入**光斑支撑半径，F>0.5 时告警 fraunhofer_nearfield）。

### 4.4 算法选择（auto）

auto 始终选择 ASM（精确）。近似方法仅在显式指定时使用并自动告警——**准确性与速度的取舍由用户显式做出**。

## 5. 薄元件模型

全部元件以复透过率（+可选琼斯矩阵）在一个平面上作用于场。各元件的数学形式与参数见 /api/catalog（中文说明）与 optics/elements.go：

| 元件 | 透过率/相位 |
|---|---|
| 透镜 | exp(−ik r²/2f)，可带圆孔径 |
| 柱面透镜 | exp(−ik u²/2f)，u = cosθ·x + sinθ·y；垂直方向完全不改变（一维/柱面几何的原语） |
| 光阑 | 圆/矩形/椭圆/环/多边形/双缝，硬边或 erf 软化（edge_sigma） |
| 切趾器 | A·exp(−r²/w²) |
| 振幅光栅（正弦） | ½(1+m·cos(2πu/Λ+φ₀)) |
| 相位光栅（正弦） | exp(i·(m/2)·sin(2πu/Λ+φ₀))，m 为峰峰值相位（Raman-Nath 薄光栅） |
| 二元/闪耀光栅 | 占空比方波；锯齿相位（深度 blaze_depth） |
| 轴锥镜 | exp(−ik(n−1)α·r) |
| 螺旋相位板 | exp(i·ℓ·θ)，可叠加焦距 |
| 楔形棱镜 | exp(−ik(n−1)α·u) |
| 波带片 | 环半径 r_m² = mλf + (mλ/2)²（精确点-点成像公式），0/π 相位或明暗交替 |
| 漫射体 | 高斯相关随机相位（相关长度 ℓ、标准差 σ，种子可复现）；屏锚定到元件的**物理坐标**，平移元件即改变散斑 |
| **克尔介质** | 强度相关折射率：相位 φ = k·n₂·I·L（I=\|E\|²，W/m²），可选双光子吸收 β·I·L |
| **可饱和吸收体** | 强度相关吸收 α(I)=α₀/(1+I/I_sat)：弱光被吸收、强光透过 |
| 反射镜 | 振幅反射率 ρ；球面曲率相位 exp(−ik·curv·r²)（等效焦距 R/2）；倾角偏转 2θ |
| 凹面镜 | 会聚球面反射镜：exp(−ik·r²/R)，等效焦距 f=R/2（曲率半径 R>0），可带孔径/反射率 |
| 凸面镜 | 发散球面反射镜：exp(+ik·r²/R)，等效焦距 f=−R/2（曲率半径 R>0），可带孔径/反射率 |
| 泽尼克板 | Noll 序 Z1–Z21 波前像差（单位 λ，归一化半径可调） |
| 偏振片/波片/旋光片 | 琼斯矩阵（见 §7） |
| 自定义琼斯 | 任意复 2×2 矩阵 |
| 分束器/合束器 | 对称 BS：t=√(1−R)，r=i√R（见 §6） |
| **脚本元件** | 用户定义文件里的表达式：复透过率 t = amp·e^{iφ}（+可选琼斯矩阵），见下 |
| **厚透镜** | t(r) = exp(i·k₀·(n(λ)−1)·thick(r))，thick = d + sag₂(r) − sag₁(r) 由两面球面/圆锥矢高导出；model=equivalent 时改用厚透镜几何焦距的等效薄透镜（见 §5.2） |
| **镀膜（多层膜）** | 各向同性膜堆特征矩阵法（TMM）：复透过幅值按功率归一（\|t\|² = T），s/p 分别作用于 Ey/Ex；反射部分不进入光路（见 §5.2） |
| **GRIN 板** | exp(i·k₀·d·(n₀ − 1 + Δn(x,y)))，Δn = c₂r²+c₄r⁴+c₆r⁶（或表达式）；纯二次项即薄透镜 f = −1/(2c₂d)（见 §5.2） |

薄元件标量模型的适用边界：结构远大于 λ、傍轴、无强偏振耦合（需要时用琼斯元件处理）。

**一维（柱面）几何**：柱面透镜只对 u 方向施加二次相位，垂直方向原样透过。平面波照明下的光栅图样沿沟槽方向（y）**严格不变**，所以每个级次是一条垂直于色散方向的谱线，而不是一个点——「衍射光栅光谱」模板正是用柱面傅里叶透镜把级次搬到焦面（x_q = q·f·λ/Λ）而不去动 y（回归测试 `TestExampleGratingSpectrumOrders` 第 (6) 条断言逐行核对 I(y)/I(0) = 1）。若换成球面透镜，y 方向同样被聚焦，级次退化成 λf/W_y ≈ 40 µm 的点（8 mm 窗口）——这正是该模板此前的样子。

### 5.1 脚本元件（元件定义文件）的物理约定

`elements/*.json` 定义的元件与上表的内置薄元件**同一物理模型**（逐点复透过率，可带琼斯矩阵），只是把公式写成表达式（实现见 optics/customelem.go、语言见 docs/KERNEL.md §4.1）：

- **局部坐标**：`x, y` 是元件自身平面内的坐标（元件中心为原点，u/v 轴由 yaw/pitch/roll 决定），单位为米；`r = hypot(x,y)`、`th = atan2(y,x)`。
- **相位符号**：`phase` 是弧度，透射场乘以 `exp(+iφ)`。与内置元件的约定一致——会聚透镜/凹面镜是 **负** 相位（如 `-k*r*r/(2*f)`）；`phase_unit: "waves"` 时该值先乘 2π。
- **振幅**：`amp` 是振幅透过率（不是强度），缺省 1；`|t|²` 才是能量份额。加载器在探针网格上检查 `t` 有限（NaN/Inf 报错），因为薄元件里的 NaN 会随传播扩散到整个平面。
- **偏振**：给出 `jones` 时按 2×2 复矩阵作用在 (Ex,Ey) 上；场原本是标量时会自动升级为琼斯矢量（Ey 出现）。标量情形只乘 Ex/Ey，不动 Ez。
- **反射**：`behavior: "mirror"` 的元件在反射方向发射光束时施加这个相位（振幅反射率由光路层负责，与内置反射镜一致），因此 `phase = -k*r*r/R` 的脚本镜与内置凹面镜逐像素等价（回归测试锁定 1e-12）。
- **逐点性**：表达式只能看到本点的 (x,y) 与波长，看不到场的全局信息；因此它表达不了按峰值归一化、卷积、迭代优化这类算子（要做这些请写原生元件）。
- **相干性**：脚本元件不引入新的相干/非相干分组——它只是每个相干单元各自被乘一次复透过率，干涉与分组规则完全不变。
- **色散**：`λ`（以及 `k = 2π/λ`）是运行时波长。写成 `-k*(√(r²+f²) − f)` 得到与波长无关的几何程差（理想透镜），写成 `-(2π/λ0)*(√(r²+f²) − f)`（λ0 为设计波长参数）则是真实衍射元件的色散：焦点随 f·λ0/λ 移动（示例 elements/metalens.json，测试 TestScriptedMetalensChromaticShift 锁定 400 nm 时焦点移到 0.475 m）。

### 5.2 局部折射率不均匀元件：厚透镜 / 镀膜 / GRIN 板

三个原生薄元件（登记名 `thick_lens`、`coating`、`grin_plate`；实现见 optics/elem_thicklens.go、elem_coating.go、elem_grin.go，参数与中文说明见 /api/catalog）。它们都遵守本节的薄元件约定：在一个平面上乘复透过率，Ex/Ey 同乘（镀膜按 s/p 分别乘）。

**厚透镜 `thick_lens`**。两面顶点曲率半径 R1、R2（米）与中心厚度 d，矢高

    sag_i(r) = r² / (R_i·(1 + √(1 − (1+k_i)·r²/R_i²)))      （精确圆锥矢高，k_i=0 为球面）

R_i = 0 或 ±Inf 表示平面；**符号约定：R > 0 表示曲率中心在出射侧**（与经典透镜公式同约定：双凸透镜 R1>0、R2<0）。r 处玻璃厚度 thick(r) = d + sag₂(r) − sag₁(r)（傍轴 ≈ d − (r²/2)(1/R1 − 1/R2)），复透过率取程差

    t(r) = exp(i·k₀·(n(λ) − 1)·thick(r))，  k₀ = 2π/λ

推导：在镜前后各取一参考面，半径 r 的光线穿过「空气 → 玻璃 thick(r) → 空气」，与轴上光线（穿过 d 玻璃）相比的程差正好是 (n−1)·thick(r)，横向相位

    φ(r) ≈ −k₀·(n−1)·(r²/2)·(1/R1 − 1/R2) = −k₀·r²/(2·f_mask)，f_mask = 1/((n−1)(1/R1 − 1/R2))

即与内置 `lens` 同号的会聚相位（§1 时间约定下 focus 在 +f 处）。材质色散用内置 Sellmeier 表（N-BK7/FusedSilica/N-SF5/N-SK16/F2，系数与出处写在 elem_thicklens.go，或用 material=constant 给固定 n）；波长超出标定范围会告警 `thick_lens_glass_range`。

**与厚透镜几何公式的关系（关键，写错就错焦距）**：镜片目录的焦距是从**主平面**量起的

    f_geo = 1/((n−1)·(1/R1 − 1/R2 + (n−1)·d/(n·R1·R2)))

其中的 (n−1)²d/(nR1R2) 是「第二面位于第一面之后 d/n」带来的功率叠加项，来自**玻璃内传播**；单个相位平面表达不了主平面偏移，所以默认模型（`model=sag`）给出的焦点是 f_mask（上式 d→0 的极限）。需要直接得到目录焦距时用 `model=equivalent`：元件改为施加等效薄透镜 exp(i·k₀(n−1)d)·exp(−i·k₀r²/(2·f_geo))（此时忽略圆锥常数）。两者之差对 R=±60 mm、d=12 mm 的 N-BK7 是 3.5%（f_mask=58.24 mm vs f_geo=60.29 mm @632.8 nm）；回归测试 elem_thicklens_test.go 分别断言两个模型的焦点位置（±1.5% 内，扫描 0.6 mm 步进 + 抛物线细化）。若需要「真实厚透镜」（含镜内光线折转），应拆成两个面 + `medium(index)` 的 d/n 传播——本元件是这一个相位平面的模型。

**镀膜 `coating`**。各向同性多层膜，用特征矩阵法（TMM）算复透过/复反射：每层 j 的复折射率 N_j = n_j + iκ_j（κ>0 吸收，与本内核 exp(−iωt)/e^{+ikz} 约定一致）、厚度 d_j，倾斜光学导纳 η_j = N_j cosθ_j（s）或 N_j/cosθ_j（p），层相位 δ_j = k0·(N_j cosθ_j)·d_j，层矩阵

    M_j = [[cos δ_j, −i·sin δ_j/η_j], [−i·η_j·sin δ_j, cos δ_j]]

（**−i 来自内核的 e^{−iωt} 约定**；用 e^{+iωt} 的教科书写作 +i，两者只差 t 的相位共轭——|t|、R、T 相同，相位相反，所以测试用「单层界面方程直接求解」钉住相位）。堆栈矩阵 M = M₁M₂…M_k（**顺序不可交换**，测试用 (HL)⁴ 四分之一波堆的解析式锁定），[B;C] = M·[1;η_sub]，

    t = 2η₀/(η₀B + C)，  r = (η₀B − C)/(η₀B + C)，  R = |r|²，T = Re(η_sub)/Re(η₀)·|t|²

无损堆栈 R + T = 1（测试 1e-15），吸收层 R + T < 1。斜入射用复形式的 Snell 定律 N_j cosθ_j = √(N_j² − N₀²sin²θ₀)（分支 Re ≥ 0、Im ≥ 0：传播波前进、吸收/衰逝衰减）。

- **偏振**：θ₀ 的入射面默认取元件局部 x–z 面，于是 s = 局部 y（Ey）、p = 局部 x（Ex），元件作用 diag(t_p, t_s)；`plane=y` 交换。标量（Polarized=false）场只带 x 分量（§7），取 x 系数。θ₀ 是**整个元件的单一设计角**：薄元件是逐点算子、看不到局域波矢，因此会聚/发散光束的角分布不建模（文档明示的近似）。
- **幅值按功率归一**：内核的场不携带介质导纳变化（元件后光束仍走同一网格、|E|² 就是功率密度），所以元件施加 √(Re η_sub/Re η₀)·t（`ThinFilmEffectiveAmplitude`），使透过功率恰为 T——裸界面（0 层）这时给出 4.3% 的 Fresnel 反射而不是 |t|² 的 37%。相位不受影响；`ThinFilmCoefficients` 仍返回薄膜理论的原始系数。
- **材质色散**：常数 n(,k)、Cauchy（n = A + B/λ² + C/λ⁴，λ 以 µm 计）、Sellmeier（n² = 1 + ΣB_iλ²/(λ² − C_i)）、(λ[nm], n, k) 插值表；内置 MgF2（Dodge 1984 Sellmeier）、SiO2（Malitson 1965）、Ta2O5（Gao 2012 常数近似，注明未含色散）、以及厚透镜的玻璃表（衬底用）。出处写在 elem_coating.go 的注释里。
- **与 optics/berreman.go 的关系**：berreman.go 是各向异性**体介质**的 4×4 传播（ε 张量、o/e 耦合）；本元件是各向同性**膜堆界面**响应的 2×2 特征矩阵（s/p 不耦合，因而精确且更便宜）。二者无重复实现：需要体传播用 `medium`/`biaxial`，需要表面镀膜用本元件。
- 测试（elem_coating_test.go）：单层与「界面边界条件直接求解」逐点吻合（|Δt| < 1e-14，含吸收与斜入射）、裸界面 Fresnel、四分之一波单层等效导纳解析值、四分之一波堆解析式（并锁定层序不可交换）、能量守恒、相位约定（薄膜相位 ≈ +k₀nd）、s/p 作用与标量路径、四种色散形式与报错路径、12 层反射镜 T < 2%。

**GRIN 板 `grin_plate`**。厚度 d、横向折射率 n(x,y) = n₀ + Δn(x,y)：

    t(x,y) = exp(i·k₀·d·(n₀ − 1 + Δn(x,y)))

横向相位 k₀·Δn·d 是元件的主物理；(n₀−1)·d 项是板在空气里的活塞（与轴锥镜/楔形棱镜的 (n−1) 约定一致，n₀=1 时无此项；需要完整介质传播请用 `medium`）。Δn 取径向多项式 c₂r²+c₄r⁴+c₆r⁶（r 以米计）或表达式 `expr`（脚本元件语言，变量 x,y,r,th,wl,k 与元件参数；构造时在探针网格上检查有限性）。纯二次项即薄透镜：

    φ = k₀·c₂·d·r² = −k₀·r²/(2f)  ⇒  f = −1/(2·c₂·d)      （c₂<0 会聚，与真实 GRIN 棒一致）

测试（elem_grin_test.go）：逐点相位、纯二次 GRIN 与同焦距 `lens` 的场逐像素一致（相对 L2 < 1e-12）且焦点一致、表达式与多项式等价、口径/挡光/边缘软化、参数与表达式报错、场景 JSON 端到端。

### 5.3 自定义不均匀介质（`custom_medium`：表达式 n(x,y,z,λ) + z 分层）

前面两节都是**薄元件**（一个平面上的复透过率）。本节是**介质**：光在其中的**一段 z 区间内传播**，折射率由用户以表达式逐点给出 —— n(x,y,z,λ)，可选吸收/增益 k(x,y,z,λ)。实现：optics/medium_custom.go（模型与元件）、optics/medium_expr.go（表达式编译）、optics/medium.go 的 `PropagateSplitStepRef`（引用折射率 split-step）；目录项与中文参数说明见 /api/catalog。

**介质定义（JSON）**。两种等价写法：分层 `layers`（1..N 层，沿 z 顺序堆叠，层外为真空）或单层简写 `distance`+`index`（与内置 `medium` 元件同形）：

    {"type": "custom_medium", "params": {
       "steps": 40,                                  // 切片总数（按层厚比例分配，每层≥1）
       "layers": [
         {"thickness": 1e-3, "index": "1.5 + 1e-3*z/1e-3"},                 // 渐变平板
         {"thickness": 0.5e-3, "index": "n0 + g*x", "params": {"n0":1.5,"g":300},
          "absorption": "2e-4*step(1e-3 - r)", "reference": 1.5, "steps": 60},
         {"thickness": 1e-3, "index": "1.0"}             // 层外/层内均为真空段
       ]}}

表达式语言与脚本元件**同一套**（词法/语法/函数表复用 optics/expr.go，编译器见 medium_expr.go），变量多一个 z 与 zl：

| 变量 | 含义 |
|---|---|
| `x, y` | 横向坐标（网格系的米） |
| `z` | **距介质入射面**的深度（米），跨层连续 |
| `zl` | **距本层入射面**的深度（米），每层重新从 0 计 |
| `r, th` | hypot(x,y)、atan2(y,x) |
| `wl, k` | 波长（米）与 k=2π/λ；另有 `pi, e` 与 `params` 里的命名常量 |

函数：sin/cos/tan/asin…/exp/log/sqrt/abs/sign/floor/ceil/round/min/max/pow/hypot/mod/clamp/`if`（**惰性求值**，可用来绕开奇点）/step/rect/smoothstep/erf/sinc/rad/deg。未知变量、未知函数、参数个数不符、语法错都在**加载时**报错并给出列号（`column N: ...`），不会静默取 0。`index` 是 n 的**实部**（须 >0），`absorption` 是 **Im(n)**（>0 吸收、<0 增益，可为空间分布）。

**传播算子（引用折射率 split-step）**。每层、每个厚度 dz 的切片（中心深度 zc）作用：

    E ← ASM_{nref}(dz/2) · [ exp(i·k₀·(n(x,y,zc) − nref)·dz) · exp(−k₀·Im n(x,y,zc)·dz) ] · ASM_{nref}(dz/2)
    ASM_{nref}(h) = F⁻¹{ F{E} · exp(i·h·√((nref·k₀)² − (2πf)²)) }        （介质内的角谱核）

`nref` 是该层的**引用折射率**：给了 `reference` 就用它；否则取该层表达式在**光轴上、层中点**的值（n(0,0,d/2)，在运行波长下求值，故色散表达式也跟着 λ 变，可用 `CustomMedium.LayerInfo(λ)` 查询实际取值）。`zl` 与 `z` 都按"距入射面"定义，因此层厚与层内渐变可分别书写。

这与既有的 `PropagateSplitStep`（引用折射率恒为 1：真空衍射核 + 全量 (n−1) 相位屏，内置 `medium`/`uniaxial` 元件用的就是它）是**同一算子的不同参考点**：`PropagateSplitStepRef(..., nref=1, ...)` 与 `PropagateSplitStep` 逐比特一致（测试锁定），而 `nref = 该层折射率` 时——

- **空间均匀的层被精确传播**：相位屏恒等于 1（n−nref≡0），只剩介质内角谱核。对每个平面波分量这是均匀介质亥姆霍兹方程的**精确解** `exp(i·d·√(n²k₀²−kt²))`：轴向光程 k₀·n·d、界面折射（内部角 θ/n）与"缩减厚度" d/n 全部正确，切片数对该层不再影响结果（核在频率域对角，切片相位相加；不同均匀层因此**严格可交换**，测试锁定 1e-12）。
- 对比之下 `reference: 1`（或真空核）的均匀层只是**纯相位屏**：平行玻璃板不折射、焦点不动（测试断言位移 0.0000 mm）——这正是 §5.2 GRIN 板小节说"需要完整介质传播请用介质元件"的原因。

**离散与误差**。Strang 对称分解 [ASM dz/2, 屏 dz, ASM dz/2]：

- 均匀层：**无离散误差**（上述精确解），实际误差只有浮点舍入（实测轴向相位误差 ~1e-12 rad）。
- 横向渐变层：局部误差 O(dz³)、全局 O(dz²)（衍射算子与横向相位屏的对易子）。精度条件 **|n − nref| ≪ nref**（引用折射率要接近局部折射率；自动取轴上值在傍轴、弱梯度情形已足够，强梯度/离轴光束可显式给 `reference`）。若把 n 与 nref 之差当作微扰的**一阶**项，模型给出的横向偏折为 dθ/dz = ∂(n−nref)/∂x，与精确光线方程 dθ/dz = (1/n)∂n/∂x 相差 O((n−nref)/nref)——即"nref 取局部值"时的标准 BPM 精度。
- z 渐变层：屏随 z 变化，需要足够切片；平滑渐变 20–100 片即可（实测 ∂n/∂z=400 /m、dz=2.5 µm 时相位误差 3e-13 rad）。

**采样判据与稳定性**（三条，均可自行核算）：

1. **横向相位屏采样**：k₀·|∂n/∂x|·dz·dx ≤ π（每像素相位步进 < π）。超出时内核告警 `custom_medium_alias`（给出该层实测最大 rad/像素），强烈建议按 dz 或 dx 加密——否则相位屏混叠。
2. **网格 Nyquist 角**：介质造成的**总**波前倾角须 < λ/(2dx)（例如 dx=15.6 µm、λ=632.8 nm 时 20 mrad）。这是网格能表示的最大方向余弦，与 §3 的角谱采样极限同源：偏折过大的光束频谱越过 Nyquist 后会被循环卷积绕回窗口（此时 ASM 自身的 `asm_alias_wrap` 也可能告警）。强偏折介质请减小 dx（增大 N）或缩短作用长度。
3. **衰逝波**：介质内的截止在 kt = nref·k₀（而非真空的 k₀），即"折射率抬高带边"；核按与真空核相同的策略处理（前向物理衰减、`evanescent_limit` 截断、反向置零/Tikhonov）。深衰逝分量不改变结果。

**吸收/增益**。Im(n) 无参考项：场每片乘 exp(−k₀·Im n·dz)，即**振幅**衰减；强度按 exp(−2k₀·Im n·L) = exp(−α·L)（α = 2k₀·Im n 为强度衰减系数）。Im n<0 为增益（同一公式符号相反）。空间分布的吸收（如 `2e-4*step(1e-3-r)` 的吸收圆盘）逐点生效：只衰减被照到的区域。

**数值保护**。构造时在探针网格（x,y∈{0,±1,±4 mm}，z∈{0,d/2,d}）与运行波长下分别检查表达式：非有限（NaN/Inf）或 n ≤ 0 立即报错（含出错坐标，并提示用 `if()/clamp()` 绕开奇点）；逐点求值时若出现非有限值，该片立即以带坐标的错误终止，绝不会让 NaN 扩散到整个平面。表达式**只编译一次**（元件构造期），传播循环里只做闭包求值；空间均匀层更是退化为"每片一个复标量乘"。

**限制（与 §5 薄元件模型一致的取舍）**：① 前向 split-step，**不含界面菲涅耳反射/透射振幅因子**（n=1.5 的单界面 4n/(n+1)² = 0.96 被忽略，即约 4% 的振幅误差，若关心反射率请显式加 `coating` 类元件）；② 傍轴（角度上限即判据 2 的 Nyquist 角）；③ 介质厚度在元件内部推进，**定位场景**里后续元件的位置不会自动加上这段厚度（与内置 `medium` 元件同一约定）；④ 层数 ≤64、切片总数 ≤4096、总厚度 ≤1 m（防内存/CPU 失控）。

**实测（go test ./optics/ -run CustomMedium）**：

## 6. 折返光路与干涉（关键物理约定）

- propagate 的距离是**沿光束自身传播方向的路程**，永远取正值；反射镜翻转传播方向，但相位继续按 **+ik·(路程)** 累加：来回 2L 的相位是 **2kL**。
- 用逆传播（−z）代替折返会抵消去程相位，破坏干涉仪物理——本内核不这样做（迈克尔逊能量守恒测试验证了此约定）。
- **分束器**：主光路继续透射臂 t=√(1−R)；反射臂场 = i√R·e^{iφ}·U_in，作为子光路独立演化（可再含反射镜/分束器，嵌套最多 8 层），最终在**合束器**处按任意复权重相干叠加：

      out_j = Σ_i w_ji · arm_i

  对称 BS 再合束（out1 = t·A + ir·B，out2 = ir·A + t·B）即标准马赫-曾德尔/迈克尔逊输出端口。合束器必须位于光路末端；各臂网格像素尺寸须一致（Fraunhofer 会改变像素尺寸，不能直接合束）。

## 7. 琼斯偏振

- 光源琼斯矢量预设：x/y/d/a/r/l/自定义（自动归一化）；polarized:false 时仅演算 Ex（标量模式，速度 ×2）。
- 元件琼斯矩阵：偏振片 P(θ)、延迟片 R(−θ)diag(e^{iδ/2}, e^{−iδ/2})R(θ)（δ=π/2 为 QWP，π 为 HWP）、旋光片 R(α)、任意自定义矩阵。标量场遇琼斯元件自动升维为矢量场。
- 视图可分别显示 |Ex|²、|Ey|²、总强度与两分量相位。

## 8. 光源与功率归一化

光源类型：平面波（精确方向余弦倾角）、高斯、拉盖尔-高斯 LG_p^ℓ、厄米-高斯 HG_mn、贝塞尔（截断）、球面波（发散/会聚）。所有光源**数值归一化**使 ∫I dA = power（W，默认 1 mW），因此强度绝对值是物理的 W/m²，功率在透明系统中守恒（ASM 传播波部分严格守恒，测试误差 < 1e-6）。

## 9. 指标定义

- 功率 P = ΣI·dx²；峰值强度；质心 (x̄,ȳ) = Σr·I/ΣI；RMS 半径 σx,σy（相对质心二阶矩）。
- **Strehl**：传感器参数 strehl_aperture（参考光瞳半径 R）与 strehl_distance（距离 z）给定后，
  Strehl = I_peak / ( P·πR² / (λ²z²) )，即相对“同功率经同半径理想圆瞳在该距离衍射极限聚焦”的轴上强度。完美系统 ≈ 1（测试测得 0.998）。
- 一维剖面：过质心（或指定坐标）的 3 像素厚切片平均，场量可选 总强度/|Ex|²/|Ey|²/相位。

## 10. 定位场景光路模型（1.0）

光路不再存储“依次经过的元件序列”，而是存储元件的**位置、朝向与轮廓**（`scene.components[]`）：

    scene: { components: [ { id, type, label,
                             pos:{x,y,z}, yaw, pitch, roll,
                             shape:{kind,params}, params:{...} } ] }

- **坐标系**：右手系，`z` 沿光轴、`x` 横向、`y` 竖直（0 为光轴高度）；`yaw` 绕 y、`pitch` 绕 x、`roll` 绕自身法线。元件的法线为局部 +z 经 yaw/pitch 旋转，`roll` 决定轮廓（孔径/偏振片方向）在面内的取向。
- **光路由几何推导**：从光源出发，反复取沿当前方向的**最近命中**元件（`nextHit`）并处理相互作用——透射元件继续前进，反射镜/分束器按 `d − 2(d·n)n` 折转（分束器同时给出透射与反射两束），直至到达探测器（记录输出平面）或不再命中任何元件。因此**元件顺序完全由位置决定**，与列表顺序无关；同一元件可被多次命中（往返光路）。
- **通光轮廓**：元件的 `shape` 用符号距离函数描述，同时充当该元件的通光孔径掩膜（面外为非透光）。宽光束照明局部透明元件（双缝、环孔等）时，能否通过由**波场**（掩膜后功率）决定，而不是由中心光线决定；掩膜后功率为零的光束在立体视图中显示为被遮挡（虚线）。
- **折返与合并**：同一元件上**到达方向**相差很小（≲10 mrad）的多束光按**同一次访问**处理并相干合并（把各束搬到元件局部坐标系、施加相对波前倾角后进行复振幅叠加），这对倾斜反射镜臂的等厚干涉条纹是必要的；方向差异大（如 45° 折转的两个端口）视为独立光束。合并键与相对倾角参考都必须是**到达方向**，不能是元件让光束传出的方向：平面平行间隙（或腔）的返回光恰好沿镜面的“折转方向”返回，若以折转方向为键，返回光会被并进**已经出射过**的第一次访问，返回波根本不会发出——部分反射镜 `mirror(reflectivity=…)` 的双程干涉曾因此静默记录成平场（光束列表在返回处截止；`beamsplitter` 的合并键本来就是入射方向，所以当时只有它能用）。部分反射镜的两种写法现在等价：`mirror` 的“反射率”是实振幅系数，`beamsplitter` 的是功率反射率、反射分支带 i·√R。
- **环路光路的求值顺序与上限**：访问图成环（谐振腔、间隙双程）时，评估按**依赖序**进行——强连通分量整体排在消费它的访问之前，环内按首次往返的因果顺序（到达序），因此**首次往返总能完整求值**；更晚的往返沿“闭合环的边”抵达已经求值过的访问，由合并步骤计数并产生告警 `scene_cycle_dropped`（“环路光路只计入首次往返：N 条再次往返的贡献被跳过”），观察面放在环内任何距离都不再改变结果。**上限（取舍）**：结果只含首次往返（两光束近似），高反射率腔的多光束（Airy）条纹不在结果中——靠告警提示适用性。
- **向后兼容**：旧的元件序列配置由 `LayoutFromElements` 转换为场景——沿 +z 按累计 `propagate` 距离摆放元件，探测器正对来光。

## 11. 多光源与相干分组

`sources[]` 中的每个光源有独立的位置、方向、类型、波长、功率与偏振，并可指定相干组 `group`：

- **同组且同波长** → 归入同一相干单元，复振幅相干叠加（可产生干涉条纹/散斑）。
- **不同组或不同波长** → 归入互不相干的单元，最终只做强度叠加（多波长颜色的物理基础）。
- 每个输出平面保留各单元的复场 `Plane.Parts[]`，因此相位/偏振等“需要复振幅”的视图可按 `?part=N` 单独查看；强度类视图（总强度、图像）默认对所有单元求和。

## 12. 图像、偏振与相位的显示约定

- **图像视图**（`field=color`，仅 PNG）：每个像素把各光源单元的强度按光源波长映射到线性 sRGB（CIE 1931 多瓣高斯拟合）后加权相加，再做 γ 编码；亮度即真实强度（可乘曝光 `2^档`），因此“亮=强、色=波长”同时可见。剖面曲线仍可叠加（用总强度）。
- **相位视图**：`phase_x/phase_y/phase_z` 为环绕相位（LUT 循环），`phase_u` 为二维去包裹波前。为避免暗处显示随机相位，强度低于峰值某比例（默认 0.2%，可用 `mask=` 调整）的像素被掩膜（渲染为暗色），剖面中相应点被跳过。
- **偏振视图**：`pol_azimuth`（ψ ∈ [−π/2, π/2]，循环色标）、`pol_ellip`（χ ∈ [−π/4, π/4]，发散色标）、`pol_s1/s2/s3`（归一化斯托克斯）、`pol_degree`（DOP）。无光区域按 1e-6 相对峰值掩膜。GUI 在偏振视图上叠加椭圆阵列，并给出鼠标处琼斯矢量、斯托克斯参数与波前 PV/RMS。
- **波前 PV/RMS**：以去包裹相位相对于其均值（去 piston）的极差与均方根计，除以 2π 换算为波长数。

## 12.1 场景模型的数值约定（1.0 内核审查后固定）

- **反射率只施加一次**：`beamsplitter` 的 `reflectivity` 是**功率**比（振幅 √r 与 √(1−r)），`mirror` 家族的 `reflectivity` 是**振幅**反射系数（反射功率 r²，透射 1−r²）。振幅分配统一在光路展开（`launch`）里完成，元件本身只贡献曲率/倾斜相位，因此 `r²+(1−r²)=1` 在不含吸收的元件上严格守恒。
- **求值顺序为拓扑序**：按波束依赖关系（Kahn）排序访问，保证"一个访问的所有入射光都已生成"；仅按最早到达排序会在不等臂折返光路中丢掉长程贡献（半功率丢失）。
- **每个相干单元按自己的波长传播**：`(相干组, 波长)` 为一个单元，单元内的光源场、传播核与所有元件的相位都使用该波长；不同单元之间只叠加强度。
- **合并要求同一采样格**：合并前逐束核对像素尺寸（远场步进会改变 DX），不一致即报错，避免把远场数据标到名义坐标格上。矢量场（`Method=vectorial`）合并时保留并累加 Ez。
- **探测器轮廓即接收面**：探测器只测量落在自身轮廓内的光（记录平面按轮廓掩膜），因此小靶面只得到该面积内的功率；未指定轮廓的探测器记录整幅波场。合并平面（多相干单元）的功率、峰值、质心与 RMS 半径都由**总强度**重算，DOP 由各单元 Stokes 求和后计算（可 <1）。
- **掩膜语义**：相位类量在强度低于峰值 0.2%（`mask=` 可调）处视为未定义，图像渲染为暗色、剖面与 API 以 `null` 返回。
